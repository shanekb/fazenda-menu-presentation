# Fazenda menu presentation

Independent concept demo prepared for an owner discussion. This is not the restaurant's official ordering or reservation website.

Includes searchable food and drink menus, picture/list views, expandable descriptions, published menu prices, restaurant-sourced photos, and clearly labeled AI presentation previews. Six wine prices require confirmation.

Sources: the restaurant's published food and drink menus at https://fazendabraziliansteakhouse.com/ and its linked ZingMyOrder page.

Built output is published from the `docs` folder using GitHub Pages. All asset paths support the repository subdirectory.
